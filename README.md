# {Client Name} Website Design

Design artefacts for the {Client Name} website. Shared with the client at each sign-off gate.

## Structure

- `strategy/` — phase 1 outputs (BrandScript, PEACE, sitemap, page outlines)
- `brief/` — phase 2 outputs (tokens.css, components.css, style-guide.html, brief/references/)
- `copy/` — phase 3a outputs (one .md per page)
- `wireframes/` — phase 3b outputs (low-fi B&W HTML, all pages linked)
- `design/` — phase 4 outputs (high-fi HTML/CSS, client sign-off artefact)
- `assets/` — client-supplied photography, video, logos, docs. Used by designer + developer.
- `PROJECT.md` — orchestrator state, handoff log, decisions log
- `PRODUCT.md` — Impeccable strategic file (auto-loaded by every /impeccable call)
- `DESIGN.md` — Impeccable visual file in Google Stitch 6-section format
- `DESIGN.json` — Machine-readable sidecar to DESIGN.md
- `learnings.md` — client-specific preferences captured across the project
