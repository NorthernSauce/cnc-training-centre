## Eight courses. Pick the one that meets you where you are.

<!-- H2: Bucket E broetry + direct instruction. Per Ch. 9 frameworks ref. Direct routing aid for the page's structural centre. -->

<!-- Course list: VOC from sitemap §3 + existing classroom course descriptions. Em dashes in original "Beginners - Milling" converted to colons. -->

- **Beginners: Milling.** New to CNC milling. Reading a programme, setting tools, work offsets, basic G-code. Walk out able to set up a job from scratch and run it.
- **Beginners: Turning.** Same shape as the milling beginners course, on lathe simulators. Tool turret setup, work offsets, basic turning cycles, common lathe G-codes.
- **Setter / Operator: Milling.** For operators who can press cycle-start but want to set the machine themselves. Tool length offsets, work coordinate systems, edge-finding, first-off inspection, dealing with a crash without panicking.
- **Setter / Operator: Turning.** Lathe equivalent. Setting the turret, work offsets, dealing with bar feed, common turning problems on the shop floor.
- **Learn to Program: Milling.** Beyond running someone else's programme. Writing G-code by hand for milling work, canned cycles, cutter compensation, sub-routines. You leave able to write a programme from a drawing.
- **Learn to Program: Turning.** Lathe programming from scratch. Roughing and finishing cycles, threading, grooving, parting. You finish able to programme a typical turned part hand-coded.
- **Macro Programming.** For programmers who want to move past basic G-code into parametric programming. Macro variables, IF/THEN/GOTO logic, custom canned cycles, talking to the control properly. Separates programmers from people who copy programmes.
- **Edgecam.** CAD/CAM training in Edgecam, using my professional licence in the classroom. Cover the workflow from importing a model to posting tested G-code. Suits programmers moving from hand-code to CAM, or companies adopting Edgecam in-house.

Each course runs scheduled or on-demand if you've got two or more. Application is per course.

## What gets asked before someone applies?

<!-- H2: Formula B from Ch. 10 (curiosity gap). FAQ section opener. Distinct from Onsite + Programming FAQ Hs. -->

**Will this course get me a job?**
Honest answer: a certificate alone won't. A certificate plus the skills you'll actually use on the floor, plus the willingness to start somewhere and learn, will. I've had students go from a beginners course to an operator job within a month. I've had others struggle because they wanted the qualification more than they wanted the work. The course is part of the answer, not the whole answer.

**Which course do I need?**
If you've never run a CNC, beginners. If you can press cycle-start but can't set the machine, setter/operator. If you can set it but you've never written a programme from scratch, Learn to Program. If you're an experienced programmer who's never touched parametric code, macro programming. If you're not sure, call me. Five minutes on the phone usually settles it.

**How many people are on each course?**
One to six. The course runs even with one applicant. You just get a much more intensive week of one-to-one time.

**Can my employer pay for me?**
Yes, lots do. I'll invoice the company direct, or you can pay and reclaim. Either works. Happy to talk to your manager if it helps the conversation.

**Are the simulators the same as real machines?**
The simulators run real controls. Same Fanuc, Heidenhain, Siemens, Mazak interfaces you'll see on the shop floor. The G-code you write in the classroom runs on a real machine without rewriting. The only thing missing is the swarf.

**Do you offer accommodation?**
No. Barwell has half a dozen hotels and B&Bs within ten minutes. I'll send a few recommendations with the booking confirmation.
