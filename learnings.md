# Client-specific learnings — CNC Training Centre

Append-only. Dated one-liners. Things specific to this client that future PMs / specialists should know.

- 2026-05-15 — Voice is the hardest constraint on this project. David's organic articles (Fanuc, Sliding Head) are the voice gold-standard; existing AI-written SEO pages (Doosan, Hurco) are the negative reference. Any copy that drifts toward corporate / "wooden AI" gets bounced.
- 2026-05-15 — The Learning Hub is the marketing engine. ~10 enquiries/day come through content. The hub is not a TAYA "build trust over 12 months" play — it's already working. Treat it as an archive + discovery layer for 300+ existing pieces, not as a fresh content programme.
- 2026-05-15 — Filterable taxonomy on the Hub: primary axis is machine/control brand (Fanuc, Siemens, Heidenhain, Mazak, Hurco, Haas, Brother, XYZ, Sliding Head, Edgecam, Doosan). Secondary: skill level, content type, topic.
- 2026-05-15 — Photography gap: no usable people / classroom / teaching photography at brief sign-off. Workshop fragment shots planned at launch; David-teaching shoot deferred post-launch. Flag for site refresh once shoot done.
- 2026-05-15 — Logo asset is PNG only (`assets/logos/cnc-training-centre-logo.png`). SVG version preferred for crisp rendering at any size — to be requested from client at next handoff.
- 2026-05-15 — **VOICE RULE: First person singular, always.** David is the only person in the business. Copy NEVER uses "we", "us", "our". Use "I", "me", "my" throughout. Exception: "Contact David" / "Tell David what you need" as direct CTAs (proper-noun form is warmer than "Contact me"). Inside body copy: first person singular. This applies to every page — homepage, services, about, hub, contact. Any copy that drifts to "we" gets bounced.
- 2026-05-16 — **NEVER WRITE A SURNAME FOR DAVID.** The site refers to "David" everywhere — first name only. An agent invented "David Smith" on the About page. Dave caught it: "you're making shit up which should never ever happen". The real surname (only ever found in one Google review attribution by Jose Luis Sampaio) is **Garner** — but the canonical reference across PRODUCT.md, strategy/, copy/, and learnings/ is just "David". DO NOT add a surname unless the client confirms it should appear on a specific page (legal byline, footer copyright, etc.). When in doubt: first name only.
- 2026-05-18 — **Designer authorised to run autonomous on a revision pass** when the trigger is a copy refresh against an already-locked visual vocabulary (i.e. Home is signed off and other pages just need the new copy + already-decided cross-page fixes applied). Dave: "designer can go off and update all the pages without me." Default rule (Design = Dave-collaborative) still applies for fresh creative direction on a new project / new page from scratch. Apply judgement: copy-refresh-into-existing-vocabulary = autonomous OK; creative direction = collaborative.
- 2026-05-17 — **NO SAAS-TEMPLATE HOVER OR MOTION ON CARDS.** Designer shipped `translateY(-2px)` lifts + 3px primary-coloured left-bar reveals on `.svc-card`, `.hub-card`, `.t-card`. Dave: "why have the service cards got that awful hover effect with the blue line on the left?? you're being lazy designer". This site's visual world is **paper, draftsman, engineering, editorial restraint**. Banned on every card / row / link: `translateY` lifts, scale transforms, coloured-bar reveals, glow / shadow appearances, arrow `translateX` shifts on hover, colour-bloom on summary hover. Allowed: hairline border colour shifts (`rule → rule-strong`), quiet ink colour shifts, underline reveals on text links, focus rings (a11y), functional state transforms (drawer open/close, FAQ +/- rotate). **Pre-write check before any hover rule:** "would this appear in NYT, Bloomberg Businessweek, FT, or a typeset engineering catalogue?" If no, kill it. Applies project-wide, not just home.
