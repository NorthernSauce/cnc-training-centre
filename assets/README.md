# Assets

Drop any client-supplied photography, video, logos, brochures, or other media here. The designer (phase 4) and developer (phase 5) read this folder for real imagery to embed.

Structure:
- `photography/` — shop-floor / location / portrait / product / detail shots
- `video/` — any video clips
- `logos/` — vector SVG when available, plus sub-marks / alt versions
- `docs/` — capability sheets, certificates, brochures, anything print-ready

Notes:
- Prefer .webp for photography (with .jpg fallback) and .svg for logos.
- Keep file names lowercase-with-hyphens.
- Hero images target ≤ 200KB. Card images target ≤ 80KB.
